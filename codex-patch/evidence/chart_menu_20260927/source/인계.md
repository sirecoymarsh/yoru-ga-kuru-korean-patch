# 도움말 메뉴 「이벤트 플로우 차트」 — 인계 (2026-09-27, Claude Fable 5.1)

사용자 결정(09-27 17시): 전체 접근(검수용) 플로우 차트는 게임 안 창이 아니라 **바깥 창**으로 열고, **게임 창 상단 메뉴바에서만** 열리게 한다. 후크 수정은 Claude 가 맡는다.

## 무엇을 하나
- 게임 창 메뉴바 「도움말(H)」에 **「이벤트 플로우 차트(E)」** 항목을 「플레이 매뉴얼(M)」 바로 뒤에 넣는다. 누르면 `<실행 파일 폴더>\Manual\chart\yoru_flowchart_v2.html`(PC 차트 v2, 단일 파일 5.3 MB)을 기본 브라우저로 연다(ShellExecuteW "open").
- 게임 스크립트(AIN)에는 외부 프로그램을 여는 기능이 없어, 한국어 패치의 네이티브 후크 `winmm.dll`(Codex 08-30 hangul_name_v4, 한글 IME 입력용)을 같은 소스에 이 기능만 더해 다시 빌드했다. 항목은 창이 처음 메뉴를 열 때(WM_INITMENU) 한 번만 넣고, 메뉴바 모양이 배포본과 다르거나(상단 2개, 도움말 = 글·구분선·글) 차트 파일이 없으면 넣지 않는다. 명령 ID 는 0x7E10~0x7EFF 에서 기존 메뉴가 쓰지 않는 첫 값.
- 바뀌지 않은 것: AIN·PACT·EX·FNL, 후크의 내보내기 4개(timeGetDevCaps/timeGetTime/timeBeginPeriod/timeEndPeriod), IAT 후크 2곳, 대체 글자 표 2,364행(헤더 sha256 `757865b3…` — Codex 배포 빌드와 동일), IME 동작. 가져오기에 SHELL32.dll·ole32.dll 이 늘었다.

## 검증
- 빌드: VS 2022 Build Tools x86, `/W4 /WX`, 정적 CRT. 진단·배포 두 프로필 모두 통과. 처음 두 번 실패: (1) 소스에 한글이 들어가 코드 페이지 949 경고(C4819)가 오류가 됨 → ASCII 전용으로; (2) `\u` 이스케이프가 파일에 `\\u` 로 들어가 메뉴에 이스케이프 문자열이 그대로 보임 → 코드 포인트 배열로.
- 탐침(격리 사본, 진단 빌드): `iat_hooks_installed` → `register_class_a_wrapped` → WM_INITMENU 뒤 도움말 메뉴 4개(플레이 매뉴얼 / **이벤트 플로우 차트(&E)** id 0x7E10 / 구분선 / 버전 정보) → WM_COMMAND 0x7E10 → `chart_menu_opened ShellExecuteW result=42` → Chrome 창 「밤이 온다! 이벤트 차트 v2」. 실기 클릭이 아니라 같은 메시지를 보낸 것이라 사용자 화면 확인이 남는다.
- Defender: 배포 DLL 검출 없음.
