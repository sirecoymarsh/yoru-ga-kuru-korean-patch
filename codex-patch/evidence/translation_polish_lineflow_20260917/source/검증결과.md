# 전역 쉼표 연결 줄 배치 후보

한 문장씩 재작성하지 않고, 공통 규칙으로 일반 대사/서술 5,463페이지, 11,387필드의 줄 배치를 조정했습니다.

- 기존 번역 교정 3,076항목을 포함합니다. 원래 플레이 기준본 대비 최종 변경은 13,671필드입니다.
- 쉼표로 끝나는 줄과 다음 줄을 같은 문장으로 연결하고, 실제 FNL 폭을 기준으로 띄어쓰기에서 줄을 나눕니다. 쉼표 자체를 무조건 줄바꿈 지점으로 쓰지 않습니다.
- 모든 페이지의 문장·구두점은 공백 제외 정확히 동일합니다. CODE, R/A, 페이지 수, 화자 필드는 변경하지 않습니다.
- 일반 창·표준 크기·단일 용도·연속 MSG/R/A 페이지에만 적용합니다. 동적 이름, 제어 문자, 특수 들여쓰기, 기존 제외 장면은 유지합니다. 모든 줄바꿈을 강제로 없애는 전역 R 패치가 아닙니다.
- 변경분은 모두 여유 폭 이내입니다. 인코딩 왕복, 메시지 수 100,944개, 비수정 데이터와 MSG1 외부 바이트 일치를 확인했습니다.
- 1,488페이지는 줄 수가 줄어 끝 MSG 필드를 비웁니다. 기존 R/A는 남으므로 전체 물리 줄 수·대기 횟수는 같습니다. 독립 코드 검토에서 읽음 플래그·저장 설명을 깨는 근거는 발견되지 않았습니다.
- 실제 게임의 m2247–2248 화면에서 쉼표 뒤 문장이 첫 줄로 이어지고 정상 폭에서 다음 줄로 넘어가는 것을 확인했습니다. 대기표식이 보였으며 잘림은 없었습니다.
- 시험 창이 닫혀 빈 끝줄 페이지의 백로그·표시 위치 실기 확인은 완료하지 못했습니다. 종료 원인을 단정하지 않습니다. 해당 시간대 NightRemaster Application Error 이벤트는 조회되지 않았습니다.
- 따라서 **정적 검사와 대표 대사 표시는 통과, 백로그 확인은 미완료인 별도 후보**입니다. 기존 플레이 실행본과 번역 교정 후보는 그대로 보존했습니다.

제보한 m2280–2282는 다음 두 줄과 빈 마지막 필드로 표시되도록 배치했습니다. 문장 자체는 바꾸지 않았습니다.
