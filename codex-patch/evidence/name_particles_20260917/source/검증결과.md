# 이름 조사 자동 선택

자유 입력 주인공 이름과 몬스터 이름을 표시할 때 한글 받침을 판정한다. 은/는, 이/가, 을/를, 과/와, 으로/로 및 원문 확인된 자기소개 야/이야 등에 적용한다. ㄹ 받침은 로를 사용한다.

- 표시 형식19개와 기존 함수3개에 연결. 기존 이름/몬스터 데이터는 변경하지 않음.
- 현재 글꼴의 한글2364음절 및 조사쌍11820건, 실제 몬스터85종×5쌍, 현재 MSG 이름 치환33768건 검사.
- 기존 MSG1 100944항목, 원본 CODE 구간, 전역·구조체·기존 함수서명 보존. 신규 도우미는 저장 상태를 만들거나 수정하지 않음.
- 이름 뒤에 선배/군 같은 호칭이 오면 이름의 받침으로 호칭 뒤 조사를 바꾸지 않음.
- 알 수 없는 비한글 이름의 발음은 추측하지 않고 기존 조사를 유지. 숫자는 한국어 숫자 읽기를 기준으로 처리.
- 독립 코드 검수 완료. 내부 표식은 입력 제한보다 길어 이름과 충돌하지 않으며 잘린 표식은 그대로 유지.
- 실기 화면과 기존 세이브 실제 로드는 미확인. 이전 사용자 요청에 따라 이 작업에서 앱 UI를 조작하지 않음.
- 적용 시 AIN·프로젝트 메타데이터·세이브 전체 외부 백업, 해시 대조, 설치/복구/중단 fixture 수행. 실행본의 다른 파일과 원본 세이브는 변경하지 않음.
