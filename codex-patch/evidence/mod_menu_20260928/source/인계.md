# 메뉴바 「모드」 메뉴 후크 — 인계 (2026-09-28, Claude Fable 5.1)

설계: `ingame\설계_v4_메뉴바차트.md`(A 절 + 「프로토콜(확정, 09-28 02시)」). 도움말 메뉴의 HTML 차트 항목을 없애고, 메뉴바에 「모드(M)」 메뉴를 넣은 후크 빌드. 게임 스크립트 쪽(요청 소비, r21)은 Opus 가 별도로 만든다. **설치는 r21 과 함께**(요청을 소비할 코드가 있어야 의미가 있음).

## 무엇을 하나
- 첫 WM_INITMENU 때 메뉴바가 배포본 모양(상단 2개)이면 「모드(&M)」 팝업을 「시스템」과 「도움말」 사이에 넣는다: 이벤트 플로우 차트(&E) / 전체 개방(&U) / 전체 개방 되돌리기(&R) / 구분선 / 전체 리셋(&Z) / 전체 리셋 되돌리기(&B). 명령 ID 는 0x7E10~0x7EFF 에서 빈 값 5개(탐침에서 7E10~7E14).
- 항목 클릭 → `<exe>\KRMenu\request.txt` 에 `cmd / seq / time` 3줄(임시 파일 뒤 교체). 전체 리셋·되돌리기는 먼저 네이티브 MessageBox(예/아니오, 기본 아니오)로 묻는다.
- 시작 때(첫 타이머 호출 = 엔진이 전역 파일을 읽기 전) `KRMenu\reset.req` 또는 `restore.req` 가 있고 저장 폴더에 `YoruKR_reset.marker`(같은 낱말)가 있으면: 리셋 = 전역 기록 파일 8종(NightRAFInfo/CGMode/MemMode/BGMMode/Common .asd, NightRMsgSkip.msk, CommonGameData.asd, YoruKR_HomeRate.dat; 있는 것만)을 `<save>\Backup\KR_reset_<시각>\`(manifest.txt) 에 복사(크기 검증) 후 삭제; 복원 = 가장 최근 `KR_reset_*` 에서 복사(현재 파일은 `KR_before_restore_<시각>\` 로 옮김). 표식·req 삭제, 결과는 `KRMenu\last_result.txt` 한 줄(ASCII). 세이브 슬롯·설정 파일·YoruKR_Terms.dat·YoruKR_Chart.dat 은 손대지 않는다.
- 저장 폴더 해석: `AliceStart.ini` SaveFolder + `InstallInfo\SaveFolderSetting.ini`(SFSF, 형식 2 = exe 기준; 그 밖 = `Documents\AliceSoft\<GameName>\<SaveFolder>`, Documents 는 SHGetKnownFolderPath). 해석 실패·표식 없음이면 아무것도 지우지 않고 결과만 남긴다.
- 바뀌지 않은 것: 한글 IME 후크 전부, 내보내기 4개, 대체 글자 표 2,364행(헤더 757865b3…).

## 검증 결과 (09-28 03:1x)
- 빌드: 진단·배포 통과, 단위 하네스 PASS(table=2364).
- 탐침: 메뉴바 = 시스템(&S) / **모드(&M)** / 도움말(&H); 모드 항목 5 + 구분선, 도움말은 원래 3개. chart·unlock_all·unlock_revert 요청 파일(seq 1·2·3). 전체 리셋 → MessageBox 「전체 리셋」 → 아니오: 요청 없음(로그 mod_command_cancelled) / 예: `reset_all`(seq 4). 시작 시 리셋: 전역 파일 8개 → `Backup\KR_reset_20260928_031258\`(+manifest.txt) 복사 후 삭제, 표식·req 정리, `last_result` = `reset ok KR_reset_…`. 복원: 8개 모두 복귀, `KR_before_restore_…` 생성, `restore ok …`. 설정 파일(AFConfig·CommonSystemData·Volume)·세이브(NightR07)·YoruKR_Terms.dat 은 손대지 않음.
- 확인 못 한 것: Documents 기준(형식 0) 저장 폴더 해석은 사용자 실제 환경(OneDrive 문서)이라 탐침하지 않았다. 해석이 틀리면 표식이 없어 아무것도 지우지 않고 `last_result` 에 실패만 남는다(안전). 실기 확인 항목에 넣을 것: 전체 리셋 한 번 → 다음 실행 → `KRMenu\last_result.txt` 가 `reset ok` 인지.
