# 전역 줄 배치 v2 검증 결과

- 일반 대사·서술 **12,650페이지 / 28,108필드**를 쉼표와 관계없이 페이지 단위로 결합 후 실제 FNL 글꼴 폭으로 다시 나눔.
- 기준: 쉼표 재배치 전 교정본. 이전 설치본과 차이 18,896필드. 새 의미 번역 없음. 공백을 제외한 글자·문장부호 순서 보존.
- 화자 필드, MSG 100,944개, MSG1 밖 모든 바이트 및 진행·클릭 제어 보존. 폭 초과 0.
- 독립 검수에서 찾은 접미형·단어 내부 경계 39개를 모두 보존 대상으로 전환. 모호한 경계 187페이지와 특수 형식 등은 그대로 유지.
- 제보 대사 결과: `학교 수영장이나` 다음 줄에 `가면 될 거 아냐`가 함께 옴. 개별 대사 예외 수정 없이 공통 규칙으로 해결.
- 독립 검수 및 정확한 최종 파일 Defender 검사 통과. 설치 시 외부 백업, 해시 확인, 복구 fixture와 세이브 보존 검증 수행.
- **실기 한계:** 격리 검증 실행 후 사용자가 직접 확인하며 UI 조작 중단을 요청. 제보 문장·빈 끝줄·백로그 최종 화면 검증은 완료하지 않음. Text/Face창 모두 실제 폰트 폭 정적검증만 완료.
- 검증용 실행본은 제보 문장을 초반으로 옮긴 QA 전용. 실제 설치 파일에는 해당 대사 이동이 없으며 원래 대본 순서를 유지함.

이 문서는 내부 설치 기록이며 배포 패키지가 아님.
