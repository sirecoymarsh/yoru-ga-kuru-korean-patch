# 밤이 온다! 한국어 누적 패치 선별 반영 내역

기본판은 2026년 10월 29일 누적 한국어판이다. 일본어 원문, 앞뒤 대사, 아르곤 번역과 실제 게임 메시지를 대조해 117화면의 125개 메시지를 바꿨다. 같은 대사가 여러 분기에서 재생되면 각각의 화면을 셌다.

| 구분 | 반영 화면 |
|---|---:|
| 의미·동작 | 25 |
| 말투·호칭 | 13 |
| 외래어·말장난 | 61 |
| 대사 부호 | 18 |

아르곤이 우세한 표본에서도 기존 문장과 뜻이 같거나 새 표현의 근거가 약하면 기존 문장을 유지했다. 14,939화면의 ‘승리를 갈구하는 투지의 불꽃’은 바로 앞 화면에 이미 번역되어 있었다. 화면 2,601에서는 능력 명칭이 다음 설명으로 이어지며, 학년·이름까지 곁들인 자연스러운 교체안이 얼굴창 한 줄의 668픽셀 기준을 넘겨 기존 문장을 유지했다.

7,443·34,585화면의 영어 전화 멘트는 아르곤 미반환 구간에 있다. 30,171화면의 화자·원문·직전·직후 대사가 모두 같아 같은 번역의 영어 표현을 재사용했다. 기존 아르곤 자료를 사용했으며 추가 번역 요청은 0건이다.
