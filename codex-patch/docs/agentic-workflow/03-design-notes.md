## 2. 표시·입력 계약 (WI-002)
GetSweep: 기본 false, 손상/미소유 설정도 false. SetSweep: 값 변경 시에만 저장; UI의 매 프레임 동기화가 기존 설정을 덮지 않게 한다. 공통 설정이라는 범위를 모드 페이지 설명에 유지한다.

ShowSweepButton = enabled AND eligibleOrdinaryDungeon AND mapPresent AND partyCountIn1to3 AND movablePartyCount>=1 AND remainingTime>0 AND noEventOrTutorial AND noBattle AND noBlockingModal AND state==READY. 확인 시에도 파티 수/유효 참조/행동 가능 인원을 다시 검사한다.

DEC-007의 일반 층 명시 목록, 현재 던전 ID와 지도 객체 ID 일치, EX 유효성, 현재 일반 탐색 문맥과 이벤트 객체 null을 함께 검사한다. IsRandomDungeon 또는 IsTrainingDungeon 이름만으로 허용/배제하지 않는다. 시작 ID 기반 허용을 층 이동 뒤 캐시하지 않는다. 표시와 확인 후 지급 직전 같은 공통 가드를 다시 호출한다. 이동 애니메이션·자동 이동 중에는 클릭 요청을 중복 접수하지 않는다. 맵 교체/Hide/메뉴/로드/설정 OFF 때 표시와 hit test를 함께 제거한다. 확인창은 원작처럼 배경 입력을 잠그며 키보드 초점은 취소에 둔다.

모드 페이지 우하단에는 이미 4개 체크 항목과 두 줄 안내가 있다. 다섯 번째 줄을 무작정 추가하지 않는다. 기존 하단 영역 내 재배치로 5개 항목을 수용하고 안내는 왼쪽 전투속도 아래 등 빈 공간으로 분리한다. 정확한 좌표는 FNL 실제 폭으로 검증한다. 지도 버튼은 기존 아이템/휴식 버튼과 같은 네이티브 부품 계열을 쓰고 시스템 메뉴가 열릴 때 함께 숨긴다. 원래 푸른 발광·안개·테두리·상태별 밝기를 보존한다.

## 3. 사용자 문구 (Codex internal)
- 토글: **소탕**
- 설명: **일반 던전에 자동 소탕 버튼을 표시합니다.**
- 지도 버튼: **자동 소탕**
- 확인 제목: **자동 소탕**
- 확인 본문: **남은 탐색 시간을 모두 사용해 보상을 정산하고 다음 날로 진행합니다.
보상은 현재 던전 기준의 대체 보상이며, 실제 탐색 결과와 다를 수 있습니다.
계속하시겠습니까?**
- 보조 정보: 현재 던전/층, 남은 게임 내 시간, 적용 배율. 정확한 지급액은 실행 전 확정액처럼 표시하지 않는다.
- 선택: **취소 / 소탕 실행**
- 진행: **소탕 보상을 정산하고 있습니다…**

- 완료 결과 때문에 진행을 다시 멈추는 별도 확인 버튼은 만들지 않는다. 요약 표시 후 정상 종료로 인계한다. 원작 필수 종료 대사는 정상 흐름대로 보존하므로 확인 문구와 실제 전환을 WI-004에서 함께 확인한다.
- 실패: **소탕을 완료하지 못했습니다. 보상과 탐색 시간을 복구했습니다.**는 실제 복구 검증이 성공한 경우에만 표시. 복구 불명확 상태에서 성공/무변경을 주장하지 않는다.

## 4. 보상 환산 (WI-001/003)
**확정 가능:** 현재 층 적 보상 분포, 원작 추첨, 파티/레벨/스킬/배율 보정. **미확정:** 시간당 전투·상자 접촉 횟수. 이를 혼동하지 않는다.

v1 제안은 현재 층 보상표를 고정한 표준 탐색 한 주기 (T 게임시간, B 전투, H 상자)를 정의하고 남은 R시간에 대해 B*R/T와 H*R/T를 환산하는 방식이다. T는 이동·전투·상자·함정/휴식 가정을 **하나의 공유 시간 예산**에 포함한다. 전투와 상자 각각에 남은 전체 시간을 중복 할당하지 않는다. 계수와 단위/반올림/최소 잔여시간 처리는 WI-001 산출물 reward-policy.json에 버전과 근거를 넣어 동결한다. 실측이 아니라 가정이면 그대로 기록한다. 아직 1분당 몇 회 같은 숫자를 정하지 않았다.

소탕은 실제 맵의 남은 셀을 주워 담는 기능이 아니다. 기존 획득분은 그대로 두고 **남은 시간에만** 새 대체 보상을 만든다. 미래 층 ID, 최심층 기록, 보스/이벤트 성공 플래그를 바꾸지 않는다. 짧은 잔여 시간에 최소 1전투/1상자를 강제 보장하지 않는다.

전투는 편성별 원작 정산을 순차 재사용한다. 캐릭터 레벨 상승으로 다음 전투의 EXP/훈련이 줄어드는 경우와 정수 절삭을 유지한다. 일반 상자는 원작 후보/등급/확률/상한을 쓰고 특별 보상을 해금하지 않는다. 기존 1~20배는 해당 원작 수치 보정 경로에서 **한 번만** 적용한다. 동료 특훈 배율을 엉뚱한 전투 보상에 추가 적용하지 않는다. 실시간 전투속도/즉시처치 모드는 표준 시간이나 소탕 횟수를 늘리지 않는다.

## 5. 상태·원자성·오류 계약 (WI-001/003)
OFF/HIDDEN → READY → CONFIRMING → PLANNING → COMMITTING → RESULT → EXITING.
확인 취소는 READY로, 상태/배율/파티/층이 바뀐 요청은 재확인 또는 폐기한다. PLANNING 진입 때 요청 키(런타임 세션, 장면 세대, 날짜, 맵ID, 잔여시간)를 만들고 재진입을 막는다. 키만으로 영구 중복 방지가 끝났다고 간주하지 않는다.

확인 전 원작 RNG를 소비하지 않는다. 확인 후 결과 생성은 한 번만 수행하며 화면 새로고침/실패 재시도로 다시 추첨하지 않는다. 계획 단계에서는 실제 보상/시간을 바꾸지 않는다. 계획에 필요한 RNG/맵 생성기가 원작 전역을 바꾸면 복사된 상태 또는 전용 시뮬레이션 상태에서 실행하도록 경계를 정한다.

반영 전 보상 함수의 전체 변경 집합(능력치/레벨/기술 갱신, 화폐, 소모품, 장비/요소석 저장소, 소지 상한, RNG, 시간·경과시간 부수효과)을 조사한다. 특히 Settle 시작의 L_BattleIncome::SettleOnlyMonsAtb는 파티 유효성 검사보다 먼저 호출된다. 그 실제 변경 대상과 소탕에서 유지/제외할 정책을 WI-001에서 추가 감사하고 스냅샷 범위에 포함한다. 원작 함수를 호출했다는 이유만으로 부수효과까지 안전하다고 간주하지 않는다. 검증된 스냅샷/복구 또는 완전 사전검증+실패 불가능 커밋 중 어느 방식이 가능한지 WI-001에서 동결한다. 배열과 객체의 얕은 복사로 롤백을 주장하지 않는다. 기존 보물 지급 함수는 모달 알림이 있으므로 그대로 반복 호출해 커밋 도중 이벤트루프/저장 입력을 열지 않는다.

저장·로드·옵션 변경은 반영과 인계가 끝날 때까지 막는다. ESC 취소는 확인창까지 허용하고 지급 중에는 허용하지 않는다. 중간 오류 뒤 전체 지급을 재시도하는 것은 금지한다. 처리 완료 플래그와 잔여시간 소진을 동일 반영 단위로 관리한다. 충돌 후 사용자 세이브에 반쪽 결과를 자동 저장하지 않는다. 이전 수동 세이브를 다시 불러와 다시 실행하는 것은 정상 플레이이며 외부 전역 보상 원장으로 막지 않는다.

원자적 복구를 현 엔진에서 보장할 수 없으면 먼저 범위를 수정한다. '부분 지급+남은 시간 그대로+재시도' 형태로 출시하지 않는다.

## 6. 종료·성능·관측·배포 (WI-003/004)
보상 반영 후 잔여시간을 소진하고 정상 던전 종료 블록으로 정확히 한 번 인계한다. AdvanceRemainTime의 동료 감정/휴식 제한 갱신과 LFixedIncome의 대기 동료 성장을 중복 호출하지 않는다. 다음 날은 상위 시나리오의 정상 귀환 처리를 거쳐 도달한다. 직접 날짜를 +1하고 씬을 바꾸는 구현은 금지한다.

정산 시작 전에 기존 UI로 진행 프레임을 표시한다. 그래픽·전투 행동 시뮬레이션을 돌리지 않고 보상 계산만 한다. 사용자 환경 목표는 확인창 응답 100ms, 1일 최대 정산 2초 이내이며 아직 측정값은 아니다. 목표 초과 시 별도 분석/진행 UI를 사용하고 보상을 몰래 줄여 속도를 맞추지 않는다. 큰 작업은 계획 계산만 나누고 실제 반영 중에는 게임 입력을 처리하지 않는다.

진단에는 정책 버전·대상 ID·R·B/H·배율·결과/실패 코드만 남기며 개인 경로나 세이브 내용을 외부로 보내지 않는다. 결과 UI의 근거는 반영 전후 실제 차이이고 기존 KR_LootNotice는 재사용하지 않는다.

배포는 최신 current.json 기준 최소 AIN/PACT 패치로 스테이징 후 게임 종료 상태에서만 설치한다. 원본/복구용 런타임·세이브는 수정하지 않는다. 전체 런타임은 최신/복구용 두 개만 유지한다. 새 공통 옵션 기본 OFF, 기존 설정·번역·오프닝·폰트·경로 패치는 byte/semantic allowlist로 보존한다.
