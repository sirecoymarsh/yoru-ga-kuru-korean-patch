# 밤이 온다! 화자명 사후 정규화

제미나이 재번역 결과가 나온 뒤에 쓰는 도구다. 킷(`YoruGaKuru_Remastered_Gemini_Retranslation_Kit_v1.0.2`)은 건드리지 않는다.

## 왜 필요한가

원문의 화자명은 34,091건이지만 **서로 다른 표기는 79종뿐**이다. 즉 이건 번역이 아니라 조회표다.
686개 패킷을 나눠 번역시키면 같은 이름이 패킷마다 다르게 나올 수밖에 없다 —
시험에서 `【鏡花】`가 `쿄카`·`교카`·`쿄우카` 세 가지로 갈렸다.
표 하나로 덮어쓰면 이 부류가 통째로 사라진다.

용어집으로 이미 확정되는 비율이 **96.1%**(32,752/34,091)다. 남은 58종 1,339회는
`【声】`·`【少女】`·`【男】` 같은 역할 라벨과 단역 이름이라 사람이 한 번만 정하면 된다.

## 전각공백 패딩 (미결)

79종 중 패딩이 있는 건 주인공 `【亮　　　　】`(내부 5자, 10,729회)와 복합 라벨 1종뿐이다.
1자 이름을 다른 이름들(2~3자) 폭에 맞추려는 정렬 장치로 보인다.
같은 이름이 패딩본·무패딩본으로 갈리는 경우가 0종이라 우연이 아니다.

`speaker_labels.json`의 `padding_policy`가 이걸 결정한다.

- `preserve` (기본) — 순정본과 같은 폭을 유지한다. `亮 → 료　　　　`
- `strip` — 한국어 이름 폭에 맞춘다. `亮 → 료`

**실기에서 이름판이 고정폭인지 확인한 뒤 확정할 것.** 확인 전에는 순정본과 같은 상태인
`preserve`가 안전하다. 게임이 이미 받아들이는 상태를 기준으로 삼는다.

## 쓰는 법

1. **report** — 아무것도 바꾸지 않고 현황만 본다.

```bash
python apply_speaker_labels.py --kit <킷폴더> --results <결과폴더>
```

표와 다른 표기, 그리고 아직 표에 없는 라벨에 대해 제미나이가 실제로 쓴 표기를 빈도순으로 보여준다.
`⚠ 흔들림`이 붙은 건 한 라벨을 여러 가지로 옮겼다는 뜻이다.

2. **표 채우기** — 위 출력에서 골라 `speaker_labels.json`의 `korean_core`에 넣고 `status`를 `locked`로 바꾼다.

3. **apply** — 결과를 새 폴더에 쓴다. 입력은 절대 덮어쓰지 않는다.

```bash
python apply_speaker_labels.py --kit <킷폴더> --results <결과폴더> --apply --out <출력폴더>
```

4. **검증** — 킷의 검증기로 다시 돌린다.

```bash
python <킷폴더>/tools/validate_gemini_result.py <킷폴더>/scenario_jp/packets/packet_0001.json <출력폴더>/result_0001.json
```

## 검증된 것 (2026-08-29)

합성 결과 4패킷(705엔트리, 화자명 311건)으로 확인했다.

- 표기 흔들림 3종·패딩 탈락·pending 라벨의 경쟁 표기를 전부 잡았다
- apply 후 재검사에서 불일치 0 (멱등)
- 치환 결과 4패킷 모두 킷 검증기 `PASS`

시험은 합성 데이터다. 실제 제미나이 결과로는 아직 돌리지 않았다.
