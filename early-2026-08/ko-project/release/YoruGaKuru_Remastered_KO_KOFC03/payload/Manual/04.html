4. 일반 대화 및 이벤트 화면

화면을 클릭하면 메시지가 진행됩니다.

대화 화면

주인공(플레이어)과 등장인물들이 대화를 나누는 화면입니다.


①게임 속 날짜와 요일이 표시됩니다.

②대화 중인 등장인물과 배경이 표시됩니다.

③상대 등장인물의 얼굴 CG 등이 표시됩니다.

④등장인물의 대사가 표시되며, 왼쪽 클릭하면 진행됩니다.

메시지 창 버튼

①건너뛰기 모드
　환경 설정의 지정에 따라 메시지를 건너뜁니다.

②자동 진행 모드
　환경 설정의 지정에 따라 메시지가 자동으로 진행됩니다.

시스템 메뉴

화면 오른쪽 아래의 메뉴 버튼을 누르면 시스템 메뉴가 열립니다.

SKIP

환경 설정의 지정에 따라 메시지를 건너뜁니다.

AUTO

환경 설정의 지정에 따라 메시지가 자동으로 진행됩니다.

BACKLOG

이전 메시지를 다시 표시하는 화면을 엽니다.

BACKSCENE

대화나 이벤트를 다시 보는 화면을 엽니다.

CONFIG

게임의 각종 설정을 변경하는 환경 설정 화면을 엽니다.

⇒ 환경 설정

SAVE

저장 화면을 엽니다.

LOAD

불러오기 화면을 엽니다.

VOICE

현재 표시된 메시지의 음성을 다시 재생합니다.

HIDE

메시지 창을 일시적으로 숨깁니다.
