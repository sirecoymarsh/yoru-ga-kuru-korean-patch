환경 설정


메시지 속도

　　대화나 이벤트에서 메시지가 표시되는 속도를 설정합니다.

메시지

　　메시지에 관한 각종 항목을 설정합니다.

메시지 창

　　메시지 창 표시를 설정합니다.

소리

　　전체 또는 개별 음량을 설정합니다.

입력

　　조작에 관한 각종 항목을 설정합니다.

창

　　게임 화면 표시를 설정합니다.

게임 설정

　확인
　　확인 대화 상자별 표시 여부를 설정합니다.

　　

　전투
　　전투 진행 속도와 자동 전투 지속 여부를 설정합니다.


　훈련
　　훈련 연출을 간략화할지 설정합니다.
