밤이 온다! -Square of the MOON- Remastered 한국어 패치 KOFC02

[구성]
- 일본어 원문 기반, Codex 내부 모델 한국어 번역
- 한국어 Windows 네이티브 실행
- Locale Emulator 및 런타임 인젝터 불필요
- 사용자 제공 참조 이미지 기반 한국어 타이틀·우측 코너 로고
- 기존 세이브와 분리된 SaveData_KOFC02 사용

[설치]
1. 게임을 종료합니다.
2. Install_Korean_Patch.bat를 실행합니다.
3. 요청 시 NightRemaster.exe가 있는 게임 폴더 전체 경로를 입력합니다.
4. 설치기는 원본 해시를 확인하고 백업한 뒤 패치를 적용합니다.

[검증]
- Verify_Korean_Patch.bat는 패키지 내부 파일 63개의 해시를 검사합니다.

[원본 복원]
1. 게임을 종료합니다.
2. Restore_Korean_Patch.bat를 실행합니다.
3. 설치 때와 동일한 게임 폴더를 입력합니다.
- 백업은 %LOCALAPPDATA%\YoruGaKuru_KO_Patch\Backups 아래에 보존됩니다.

[세이브]
- 기존 일본어판 세이브는 삭제하거나 덮어쓰지 않습니다.
- 한국어판은 별도의 게임 이름 및 SaveData_KOFC02 폴더를 사용합니다.
