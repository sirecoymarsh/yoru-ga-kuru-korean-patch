# 《밤이 온다! -Square of the MOON- Remastered》 한국어화 스타일 가이드

## 번역 계약

- 의미 원문: 일본어(`ja-JP`)
- 결과 언어: 한국어(`ko-KR`)
- 번역 방식: Codex 내부 모델이 일본어에서 한국어로 직접 문맥 번역
- 금지: 외부 번역 API, 범용 기계번역, 영어 등 중간 언어를 거친 번역
- 원본 게임 폴더는 패치 설치를 명시적으로 승인받기 전까지 읽기 전용으로 유지한다.

## 기본 문체

- 내레이션은 자연스러운 현대 한국어 문장으로 옮기되 원문의 1인칭 시점과 긴박도, 정보량을 보존한다.
- 료의 내면 독백은 지나치게 문어적으로 만들지 않고 10대 남학생다운 구어체를 사용한다.
- 대사는 화자의 나이·관계·성격에 맞춰 존대/반말을 유지한다. 원문에 없는 호칭이나 감정을 임의로 덧붙이지 않는다.
- 일본어 어순을 그대로 따라가지 않는다. 여러 필드로 나뉜 한 문장은 전체 의미를 먼저 번역한 뒤 필드 수를 유지해 다시 나눈다.
- 원문의 성인·폭력 표현은 완곡화하거나 수위를 바꾸지 않는다.

## 표기

- 인명과 독음이 지정된 고유명사는 `glossary.tsv`를 따른다.
- 말줄임표는 기본적으로 `……`, 장음성 대시는 `――`를 사용한다.
- 화자 표기는 `【료】`처럼 전각 괄호를 유지한다. 원문의 자리 맞춤용 전각 공백은 한국어판에서 제거한다.
- 원문의 숫자, 단위, `%s`, `%d`, `\n`, 태그, 제어 코드, 음성 ID는 보존한다.
- 작품 내 독음이 의미보다 우선하는 조어(`光狩=히카리`, `火者=카샤`, `狭間=하자마`)는 음역한다.
- 일반 UI 동사는 짧고 일관되게 쓴다: 決定=결정, 戻る=뒤로, 次へ=다음, 前へ=이전, 攻撃=공격, 防御=방어, 移動=이동, 逃走=도주.

## 화자 메모

- **하무라 료**: 주인공. 평상시에는 가볍고 솔직한 남학생 말투. 위기에서는 짧고 거친 독백.
- **카구라 이즈미**: 선배이자 천문부장. 부드럽고 차분한 말투이지만 전투 지휘에서는 단호하다.
- **나나오기 쿄카**: 자신감 있고 템포가 빠르며 자기 페이스를 유지한다.
- **미와사카 마나미**: 감정 표현이 풍부한 후배. 지나치게 유아화하지 않는다.
- **케도인 마코토**: 단련된 전투원. 간결하고 힘 있는 말투.
- **키라라**: 간사이벤 화자. 한국어에서는 의미를 해치지 않는 범위에서 경상권 느낌의 자연스러운 사투리로 옮기되 과장된 희화화는 피한다.

## 검수 기준

1. 각 대상은 `file::m[id]` 또는 `file::s[id]`의 안정 ID로 관리한다.
2. `source`와 `source_sha256`는 번역 과정에서 바꾸지 않는다.
3. 보호 토큰의 종류와 개수가 원문과 같아야 한다.
4. 일본어 잔존은 고유명사·표시 예외·의도적 효과음만 허용하며 사유를 기록한다.
5. 번역 초안과 독립 교차 검수를 분리하고, 교정 이력을 남긴다.
6. 최종 문자열 집합을 확정한 뒤에만 CP932 프록시 글자와 FNL 한글 글리프를 고정한다.
