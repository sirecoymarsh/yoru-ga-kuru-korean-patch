원본 게임 파일, 추출한 원문 데이터, 음성·영상, 실행 파일과 빌드 결과는 넣지 않았습니다. 배포 꾸러미(xdelta 차분판)는 릴리스 `patch-20261117` 에 있습니다.

## 추가·변경 사항

원판(원래 게임) 대비 이 패치가 더하고 바꾼 것을 정리했습니다. 괄호 안은 근거(진행 기록 `codex-patch/progress.md` 의 날짜 절, 폴더·파일 이름, 릴리스 태그)입니다. 확실하지 않은 것은 「(추정)」으로 표시했습니다.

### 번역 범위

- **번역 원문**: 일본어 원문 기준입니다. 처음 번역은 Codex 내부 모델이 했고(KOFC04 `README_KO.txt`), 그 뒤 여러 차례 교정했습니다(아래 「판별 변경 기록」).
- **본문 대사**: 게임 메시지 100,944개(시나리오 항목 96,470개, 약 108만 자). 이름표·선택지·내레이션 포함(`early-2026-08/handoff/지침.md`, `읽어주세요.txt`).
- **UI 문구**: 게임 스크립트 문자열, PACT 화면 구성(260개 → 이후 185개 PACT 파일 전수 점검, 2026-09-15 「Runtime UI text omissions」), EX 데이터 1,460개(아이템·기술·장비·몬스터 이름과 설명 등).
- **UI 그림(래스터)**: 타이틀·메뉴·전투·던전·지도 표식·장소 카드·장 제목·아이캐치·세이브/로드·달력·음악 감상·회상 등 글자가 든 UI 그림 약 400장을 원래 디자인(글꼴 계열·굵기·정렬·발광 효과)을 살려 한국어로 다시 조판했습니다(2026-09-12~14).
- **오프닝 영상**: 일본어 노래 가사 한국어 자막 24개 큐, 화면에 박힌 일본어 글자(로고·크레디트 등) 한국어화, 한국어 타이틀 로고. 자막이 든 오프닝 장면 그림 801장(`assets-ko/CG`). 오프닝 파일 이름이 일본어라 엔진이 못 여는 문제를 피해 ASCII 이름 `Movie/opening.apeg` 로 넣었습니다(2026-09-12).
- **이름 정책**(2026-09-15)
  - 아이템 이름: 뜻이 보이는 한국어.
  - 기술 이름: 영어 기술명은 음역, 신카이의 프로레슬링 기술은 원래 명칭.
  - 몬스터 이름: 묘사형·일반 명칭은 번역(예: 때핥이·진흙논 귀신·낫족제비·덜그럭해골, 09-24 바쿠→맥 등 8개, 09-26 경화기·중화기), 고유한 인물·생물·설정 용어(히카리 등)와 무기 고유명(카이리 등)은 유지.
  - 작중 패러디 상표·작품·캐릭터는 실제 이름으로(예: 드림캐스트), 대응이 불분명한 가공 이름은 그대로(2026-09-23).
- **미번역으로 남긴 것**
  - 이야기 장면 그림(배경·CG) 속 글자: 사용자 결정으로 조판하지 않음(2026-09-14 「User excludes displayed scene-art lettering」).
  - 부실(동아리방) 족자 글씨: 한국어화했다가 사용자 요청으로 원본으로 되돌림(2026-09-24).
  - 선제·기습 등 전투 상태 안내의 영어(First Attack / Back Attack / resting)는 원작대로 두고 한국어 주 문구를 더함(2026-09-24).

### 편의 기능 (원판에 없던 것)

대부분 게임 안 「환경 설정 → 모드」 탭(원작 탭 아래에 새로 만든 탭)에서 켜고 끕니다. 기본값은 모두 꺼짐입니다.

- **보상 배율**: 경험치·특훈·달 조각·동료 특훈 보상을 각각 1~20배로 따로 조절(2026-09-15).
- **전투**
  - 전투 속도 1~5배, 「전투 이펙트 보지 않기」(결과만 보고 진행, 처음 진형은 한 번 보여 줌), 화면 전환 대기도 전투 속도에 맞춰 줄이거나 건너뜀(2026-09-15, 09-22, 10-16).
  - 강화 자동 전투: 원작 자동 전투가 약점·명중·범위·속도·남은 적 HP·체력 소모를 따져 기술을 고름(2026-09-22).
  - 자동 회복 아이템: 영력 기준(10~90%), 회복·해독·마비 해제·부활 5종별 허용과 최소 보유량(0~99) 설정(2026-09-22).
  - 일반 적 즉시 처치: 일반 적과 닿으면 전투 없이 보상을 받고 사라짐(보스·이벤트 전투·첫 튜토리얼 제외), 받은 보상 영수증 알림(2026-09-15).
- **던전**
  - 함정 즉시 해제(2026-09-15).
  - 다음 층 최단 경로 표시(빨간 점), 백화점·수수께끼의 틈 같은 이벤트 지도는 진행 이벤트 목표·퍼즐 상태에 맞춘 안내(2026-09-15~16, 09-26).
  - 자동 탐색/자동 이동: 버튼으로 시작해 계단·안내 목표까지, 또는 공개된 칸 안에서 적·상자·함정·미방문 칸을 찾아 다님. 대화 이벤트는 자동 넘김으로 보고 이어 가고, 계단 질문을 건너뛰어 다음 층에서도 계속, 스토리 던전·휴식 지점 뒤에도 재개(2026-09-22~27).
  - 일반 던전 소탕: 남은 탐색 시간을 그 층의 원작 보상 규칙으로 한 번에 정산하고 하루 종료로 넘어감(확인 창 기본 선택은 취소, 스토리·보스 층 제외, 2026-09-16).
  - 보물상자·함정 결과 알림: 멈추지 않고 화면 구석에 2~3초 뜨는 알림(수치는 색으로 구분), 소탕 보고에 소지 한도로 못 받은 보상 목록(2026-09-17, 09-24).
- **장비**: 자동 장착·요소석 추천(균형·공격·생존·유틸리티 4기준, 미리보기 후 확인, 2026-09-17).
- **진행 정보**
  - 플레이 정보: 주인공 이름 변경(한글·영문·숫자 최대 5자), 대사 완독률·CG·회상·엔딩 달성률, 이 세이브의 이벤트 진입률(전체 1,043개 분기), 캐릭터별 남은 이벤트(장소별·날짜별·던전 파티별)(2026-09-23~24).
  - 달성률 항상 표시: 화면 왼쪽 여백에 얼굴·막대 그래프 패널, 인물 줄을 누르면 그 인물의 남은 이벤트 창(2026-09-24, 09-27, 10-18).
  - 친밀도 숫자·단계·다음 조건 표시(여주인공 네 명, 2026-09-28).
  - 스테이터스 창 「이벤트」 쪽, 토요일 특훈 상대 고르기에 「본 대화 수 / 남은 대화」(2026-09-28).
- **이벤트 캘린더**: 달(4~11월)×줄(본편·동료·던전 동행) 한눈에 보기 → 장면 목록 → 상세 보드(등장인물 초상화, 언제·인물·열람 상태·조건·줄거리, 선택지 실제 문구). 본 장면만 「다시 보기」 가능하고 재생 뒤 원래 상태로 되돌림. 줄거리 약 1,170개 작성. 아직 안 본 장면의 인물·줄거리는 가림(2026-09-27~10-18).
- **메뉴바 「모드(M)」 메뉴**(winmm.dll 후크): 이벤트 플로우 차트, 전체 개방(캘린더·회상·CG 감상), 전체 개방 되돌리기, 전체 리셋, 전체 리셋 되돌리기(백업 후 복원 가능)(2026-09-28, 09-30). 차트는 `Manual/chart/yoru_flowchart_v2.html` 로도 들어 있습니다.
- **오토 내비게이션**: 새 게임 때 대상(이즈미·쿄카·마나미·마코토·안 씀)을 고르면, 선택지 19곳에서 그 인물 쪽 답이 금빛으로 반짝이고 20초 뒤 자동 선택, 토요일 특훈 상대도 같은 방식(직접 고르면 그 답, 2026-10-15).
- **용어 표기 설정**: 光狩·火者·チロ·狭間·凍夜·真月·真夜·火群 8개 용어의 한국어 표기를 프리셋이나 직접 입력으로 바꿈. 대사·던전 이름 등에 바로 반영(2026-09-23~24).
- **저장**: 일간(999)·주간(998) 자동 저장 칸을 수동 칸 1~49와 따로 두고 맨 위에 고정, 저장 카드에 날짜·위치·레벨·이벤트 진입률·본편 진행 단계·실제 저장 시각·플레이 시간 표시, 마지막 저장 페이지 열기, 원본 저장 화면/새 저장 화면 선택(2026-09-24~26).
- **한글 이름 입력**: 한국어 IME 로 주인공 이름·용어를 직접 입력(winmm.dll 후크, 2026-08 / 09-24).
