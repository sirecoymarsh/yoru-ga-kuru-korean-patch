### C. 차트 화면 (PartsEngine, 새 그리기; 인게임 달력·달성률 패널 코드 재사용)
- 전체 화면 덮개 + 위에 달 탭 「4월 … 11월 · 회상 · 그 밖」, 아래에 칸 격자(회상 모드 배치 참조: 가로 4×세로 3 = 12칸/쪽 정도, 썸네일 칸 크기와 작은 칸 크기는 실측 배치에 맞춤), 오른쪽에 「이전 쪽/다음 쪽」「닫기」. 달 안 정렬: 날짜 박힌 카드(날짜 순) → 던전 → 인물 서랍(인물 순, 종류 순) → 회상·그 밖(그 탭에서).
- 칸 내용: CG 가 있으면 썸네일(`Ｐ＿構築手順＿ＣＧ部分拡大縮小コピー` 류로 축소) + 아래 이름; 없으면 작은 칸에 이름. 둘째 줄 「E30160 · 10/11 아침」, 셋째 줄 조건(친밀도·앞 이벤트·특훈 뒤 등, 짧게). 표식 ▲●○ 색은 달력과 같음. **잠긴 칸(안 본 것, 전체 개방 아님)**: 이름을 「？？？」로 가리고 E번호·날짜만, 회색; 클릭해도 재생 없음(안내). 전체 개방이면 모두 보임.
- 클릭 → 상세 창(select dialog 재사용: 언제·누구·유형·조건·본 것 상태·「재생」·「닫기」). 재생은 r18 의 요청 슬롯(KR_T9HomeCasual → KR_T18RunSandboxed)을 그대로 쓴다(창을 닫고 홈 루프에서 재생, 끝나면 되돌리기). 전체 개방일 때는 잠금 검사를 건너뛴다(r18 의 재생 직전 잠금 재확인에 전체 개방 예외를 추가 — KR_T18* 함수 재정의는 허용, 핀 함수는 불가).
- 화면을 닫으면 파츠를 전부 지운다(파츠 누수 0). 달성률 패널·홈 화면과 겹치지 않게 z 순서·레이어 확인.

## 검증·탐침
- 후크: 단위 하네스 PASS, 메뉴 모양 확인(모드 팝업 4~5항목), 각 항목 → 요청 파일 내용, 전체 리셋 MessageBox, 다음 실행 초기화(표식 2개·백업 존재 조건) — 격리 사본에서 실제로 전역 파일이 백업·삭제·재생성되는지, 세이브 파일·설정 파일은 손대지 않는지 해시로.
- 스크립트: VM 으로 요청 소비 4종, 전체 개방 플래그 저장·복원, 차트 칸 정렬·쪽 수·이름/E번호/조건 문구, 잠금/개방 표시, 재생 요청 경로(r18 과 동일), 파츠 누수 0. 결함 심기 8종 이상(요청 미삭제, 잠긴 칸 재생, 전체 개방 무시, 백업 없이 삭제, 설정 파일 삭제, 파츠 누수, 정렬 틀림, CG 없는 칸에 썸네일).
- 네이티브 탐침(음소거 사본): 메뉴 → 차트 → 달 탭 이동 → 잠긴 칸/열린 칸 → 상세 → 재생 → 홈 복귀 픽셀 동일; 전체 개방 → 잠긴 칸 열림 → 되돌리기; 전체 리셋 → 종료 → 재실행 → 초기화 확인 → 되돌리기 → 복원 확인. Defender, fixture, 계약(`required_mod_menu_chart_*.json`, no-restore 문장 유지), `--verify`. **설치는 하지 않는다.**

## 정정(09-28 06시) — 「상단 메뉴 플로우 차트는 인게임이랑 무관한 전체 플로우 차트 용」(사용자)
- 메뉴바 차트는 **불러온 저장과 무관한 전체 지도**다. 회상 모드처럼 **타이틀 화면에서도** 열려야 하고, 본거지에서 열어도 같은 화면이다.
- 따라서 **요청 소비를 타이틀 화면에도** 넣는다(5종 모두: 차트·전체 개방·되돌리기·전체 리셋·리셋 되돌리기). 본거지 첫 메뉴 소비(r21)는 그대로.
- **해금 판정은 전역 기록**으로: 이벤트 첫 메시지의 읽음 표시(`MsgSkip.GetFlag`, 달력의 △ 기준)와 회상 해금 등 저장 파일 밖 기록만 쓴다. 저장별 등록(`IsRegisteredEvent`)은 쓰지 않는다. 「전체 개방」(`YoruKR_Chart.dat` = 1)이면 전부.
- **재생은 게임 회상 모드의 경로**(`MemoryModeEvent_Begin` → 이벤트 → `_End`/`_Cleanup`)로, 저장이 없어도(타이틀) 돈다. 어느 종류가 저장 없이 끝까지 도는지 격리 사본에서 종류별로 실증(날짜 박힌 본편·묶음 단계·던전 사건·풀 장면·회상 재생본·선택지 있는 것·전투 있는 것). 안 되는 종류는 칸에 「재생 불가(게임 안에서만)」 표시하고 재생 항목을 빼며, 본거지에서 열었을 때만 r18 샌드박스로 재생하게 할 수 있다(2차 선택).
- 인게임 달력(플레이 정보 → 이벤트 달력)은 그대로(저장별 ○·잠금·샌드박스).
- 후크 안내 문구(「본거지 첫 메뉴에서 처리됩니다」)는 r22 설치 때 「타이틀 화면이나 본거지 첫 메뉴에서 처리됩니다」로 바꾼다.
