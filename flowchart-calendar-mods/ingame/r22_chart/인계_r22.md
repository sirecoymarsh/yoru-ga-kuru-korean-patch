  - `KR_CReplayRun` = `C_SceneModeScene@ExecScene`(게임 회상 모드의 재생 함수)을 `AFL_MemoryModeEvent_Begin` 부터 끝까지 옮긴 jam 몸체. 명령 88개가 점프 오프셋까지 같다(정적 S8). 다른 것은 이벤트 이름 하나: 회상 표 대신 `LSys3xScript::GetLabelName(no)`. 흐름 = Begin(회상 저장 슬롯 −5 에 지금 상태 저장, `_g_回想中` 켬) → `new C_SceneGame`(게임 데이터 초기화) → Prepare + `RunEvent` → End(그 저장을 불러와 Begin 뒤로 돌아옴) → Cleanup(회상 저장 파일 삭제, `_g_回想中` 끔).

- **2차 선택(본거지에서만 r18 샌드박스)은 쓰지 않았다**: 종류별 실증(7절)에서 전투 1장면 말고 모두 회상 경로로 끝까지 돌았고, 한 경로로 두면 타이틀과 본거지의 결과가 같다. 인게임 달력의 재생(r18 샌드박스)은 r21 그대로.
