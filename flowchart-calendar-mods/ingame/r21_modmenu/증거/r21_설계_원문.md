### B. 게임 스크립트 — 요청 소비 (KR_M*)
- 홈 루프(RunHome 반복, r13/r15 가 창을 여는 자리)에서 매 반복 `FileOperation.ExistFile(<GameFolder>\KRMenu\request.txt)` 를 검사(부하 확인: 1회/프레임이 무거우면 n프레임마다). 있으면 `TextFile.ReadAll` 로 읽고 `FileOperation.DeleteFile` 로 지운 뒤 처리.
  - `chart` → C 의 차트 화면을 연다.
  - `unlock_all` → 공통 설정(`CommonSystemData.SetDataInt` 또는 `YoruKR_Chart.dat`)에 전체 개방 = 1 저장, 안내 창 「전체 개방: 안 본 이벤트도 열람·재생됩니다」.
  - `unlock_revert` → 전체 개방 = 0, 안내 창.
  - `reset_all` → 게임 안 2차 확인 창(select dialog) → 확인이면 **전역 파일 백업**(`Backup\KR_reset_<일시>\` 로 `FileOperation.CopyFile`; 저장 폴더 안이라 VSFile/상대 경로로 위치를 찾는다 — 저장 폴더 절대 경로를 얻는 방법은 구현에서 확정: `SystemService.GetGameFolderPath` + `AliceStart.ini`·`InstallInfo\SaveFolderSetting.ini` 규칙, 또는 엔진 백업 API `BackupSaveFile`) → 초기화 예약 파일 `KRMenu\reset.req`(+ 저장 폴더에 표식 `YoruKR_reset.marker`) → 「게임을 종료합니다. 다시 켜면 초기화된 상태로 시작합니다」 → 게임 종료. **실제 삭제는 다음 실행의 후크 초기화(첫 타이머 호출, 엔진이 전역 파일을 읽기 전)에서** 표식 두 개가 모두 있을 때만: 백업이 있음을 확인한 뒤 전역 파일만 삭제(설정 파일·세이브 파일·YoruKR_Terms 는 남김), 표식 삭제. 백업 복원은 메뉴 「전체 리셋 되돌리기(&B)」(다섯째 항목; 최신 백업을 같은 방식으로 예약 → 다음 실행에서 복사).
  - 홈 밖(타이틀·던전·이벤트)에서는 처리하지 않고 홈에 돌아오면 처리. 타이틀 화면에서도 `chart` 를 열지 여부: **열지 않는다**(재생에 게임 상태가 필요).

## 프로토콜(확정, 09-28 02시) — 후크(Claude)와 스크립트(Opus)가 함께 지킨다
- **요청 파일** `<게임 폴더>\KRMenu
equest.txt`(UTF-8, ASCII 만). 3줄: `cmd` / `seq`(10진 정수, 프로세스 안에서 증가) / `time`(yyyy-mm-dd hh:mm:ss). 후크는 임시 파일에 쓴 뒤 교체(원자적). 게임은 홈 루프에서 `FileOperation.ExistFile` 로 보고 있으면 `TextFile.ReadAll` → `FileOperation.DeleteFile` → 처리. 모르는 cmd 는 지우고 무시. 폴더 `KRMenu` 는 후크가 만든다(게임도 없으면 만든다).
- **cmd**: `chart`(차트 화면; 1단계에서는 「차트는 다음 단계」 안내 창) / `unlock_all` / `unlock_revert` / `reset_all` / `reset_restore`.
- **전체 개방 플래그**: 게임이 저장 폴더의 `YoruKR_Chart.dat`(VSFile; 용어 설정과 같은 방식)에 int 로 저장. 0 = 본 것만, 1 = 전체 개방. 안내 창으로 결과를 보여 준다.
- **전체 리셋(reset_all)**: 게임 안 확인 창(「전역 진행 기록을 초기화합니다. 백업을 만든 뒤 게임을 종료합니다. 세이브 파일과 설정은 남습니다.」 예/아니오) → 예이면 저장 폴더에 표식 `YoruKR_reset.marker`(VSFile, 내용 `reset`) 를 쓰고 `<게임 폴더>\KRMenu
eset.req`(1줄 `reset`) 를 쓴 뒤 게임을 정상 종료(엔진 종료 함수). **백업·삭제는 다음 실행에서 후크가**: 첫 타이머 호출(엔진이 전역 파일을 읽기 전)에서 `reset.req` 가 있으면 저장 폴더를 해석(`AliceStart.ini` SaveFolder + `InstallInfo\SaveFolderSetting.ini` 형식 2 = exe 기준, 그 밖 = Documents\AliceSoft\<GameName>\<SaveFolder>; Documents 는 SHGetKnownFolderPath) → 그 폴더에 `YoruKR_reset.marker` 가 **있을 때만** → `Backup\KR_reset_<yyyymmdd_hhmmss>\` 에 대상 파일을 복사(manifest.txt 에 목록·크기) → 복사 검증(크기) → 대상 파일 삭제 → 표식·req 삭제 → `KRMenu\last_result.txt`(`reset ok <백업 폴더>` 또는 `reset failed <이유>`). 대상 파일(있는 것만): `NightRAFInfo.asd, NightRAFCGMode.asd, NightRAFMemMode.asd, NightRAFBGMMode.asd, NightRAFCommon.asd, NightRMsgSkip.msk, CommonGameData.asd, YoruKR_HomeRate.dat`. 제외: `NightR*.asd`(세이브)·`AFConfig.asd`·`CommonSystemData.sav`·`Volume.sav`·`WindowSetting.sav`·`MouseCursorSetting.sav`·`ShowDPSetting.sav`·`3DConfig.vsf`·`YoruKR_Terms.dat(.backup)`·`YoruKR_Chart.dat`.
- **전체 리셋 되돌리기(reset_restore)**: 게임 안 확인 창 → `KRMenu
estore.req` + 표식(`YoruKR_reset.marker` 내용 `restore`) → 종료 → 다음 실행에서 후크가 가장 최근 `Backup\KR_reset_*` 의 파일을 저장 폴더로 복사(현재 파일은 `Backup\KR_before_restore_<시각>\` 로 먼저 옮김) → 표식·req 삭제 → last_result.
- **결과 안내**: 게임은 홈 루프에서 `KRMenu\last_result.txt` 가 있으면 읽어 안내 창으로 보여 주고 지운다.
- 후크 로그: 진단 빌드는 `hangul_ime_hook.log` 에, 배포 빌드는 로그 없음(last_result 만).
