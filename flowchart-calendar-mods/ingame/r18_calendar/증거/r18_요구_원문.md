- `KR_T18RunSandboxed`: (1) 임시 이어하기 저장 `ResumeSave`(전용 파일 이름, 사용자 슬롯·고정 오토세이브와 겹치지 않게; 실패하면 재생하지 않고 안내 창 뒤 복귀) → (2) 새로 저장한 길이면 `RunEvent()` → `ResumeLoad`(같은 파일) — 돌아오지 않는다 → (3) 이어받은 길이면(ResumeSave 지점 뒤로 복귀) 임시 파일 삭제 후 return → 핀 함수의 `■ＡＤＶ消し` → 본거지 재구성(r15 와 같은 경로).
