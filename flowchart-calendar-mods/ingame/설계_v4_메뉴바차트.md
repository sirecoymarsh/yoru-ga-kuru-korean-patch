## 구조
### A. 네이티브 후크 (hook_chartmenu 를 이어서, 새 폴더 `hook_modmenu/`)
- WM_INITMENU 에서 메뉴바 모양이 배포본(상단 2개)일 때 **「모드(&M)」 팝업을 「시스템」과 「도움말」 사이에 삽입**(InsertMenuW MF_POPUP). 항목: 「이벤트 플로우 차트(&E)」「전체 개방(&U)」「전체 개방 되돌리기(&R)」「전체 리셋(&Z)」. 도움말의 이전 항목은 넣지 않는다(HTML 열기 제거). 명령 ID 는 0x7E10~ 에서 빈 값 4개.
- 각 항목 = **요청 파일**: `<게임 폴더>\KRMenu\request.txt` 에 한 줄(`chart` / `unlock_all` / `unlock_revert` / `reset_all`)과 일련번호·시각을 쓴다(덮어쓰기). 「전체 리셋」은 먼저 네이티브 MessageBox 로 1차 확인(「전역 진행 기록을 초기화합니다. 백업을 만든 뒤 게임을 종료합니다. 계속?」).
- 게임이 홈이 아닐 때 눌러도 요청은 남고, 홈에 오면 처리된다(아래 B). 후크는 게임 상태를 모른다 — 알려 줄 필요가 있으면 게임이 `KRMenu\state.txt`(홈 여부)를 써 두고 후크가 읽어 MessageBox 로 「본거지에서 처리됩니다」를 띄운다(선택).
- 나머지(IME 후크·표·내보내기 4개·핀 함수)는 그대로. 빌드는 `build_all.cmd 2364`. Codex 계약: `ui_hangul_input_fix.json` 갱신, 이전 chart_menu 계약을 preserves 로.

### B. 게임 스크립트 — 요청 소비 (KR_M*)
- 홈 루프(RunHome 반복, r13/r15 가 창을 여는 자리)에서 매 반복 `FileOperation.ExistFile(<GameFolder>\KRMenu\request.txt)` 를 검사(부하 확인: 1회/프레임이 무거우면 n프레임마다). 있으면 `TextFile.ReadAll` 로 읽고 `FileOperation.DeleteFile` 로 지운 뒤 처리.
  - `chart` → C 의 차트 화면을 연다.
  - `unlock_all` → 공통 설정(`CommonSystemData.SetDataInt` 또는 `YoruKR_Chart.dat`)에 전체 개방 = 1 저장, 안내 창 「전체 개방: 안 본 이벤트도 열람·재생됩니다」.
  - `unlock_revert` → 전체 개방 = 0, 안내 창.
  - `reset_all` → 게임 안 2차 확인 창(select dialog) → 확인이면 **전역 파일 백업**(`Backup\KR_reset_<일시>\` 로 `FileOperation.CopyFile`; 저장 폴더 안이라 VSFile/상대 경로로 위치를 찾는다 — 저장 폴더 절대 경로를 얻는 방법은 구현에서 확정: `SystemService.GetGameFolderPath` + `AliceStart.ini`·`InstallInfo\SaveFolderSetting.ini` 규칙, 또는 엔진 백업 API `BackupSaveFile`) → 초기화 예약 파일 `KRMenu\reset.req`(+ 저장 폴더에 표식 `YoruKR_reset.marker`) → 「게임을 종료합니다. 다시 켜면 초기화된 상태로 시작합니다」 → 게임 종료. **실제 삭제는 다음 실행의 후크 초기화(첫 타이머 호출, 엔진이 전역 파일을 읽기 전)에서** 표식 두 개가 모두 있을 때만: 백업이 있음을 확인한 뒤 전역 파일만 삭제(설정 파일·세이브 파일·YoruKR_Terms 는 남김), 표식 삭제. 백업 복원은 메뉴 「전체 리셋 되돌리기(&B)」(다섯째 항목; 최신 백업을 같은 방식으로 예약 → 다음 실행에서 복사).
  - 홈 밖(타이틀·던전·이벤트)에서는 처리하지 않고 홈에 돌아오면 처리. 타이틀 화면에서도 `chart` 를 열지 여부: **열지 않는다**(재생에 게임 상태가 필요).
